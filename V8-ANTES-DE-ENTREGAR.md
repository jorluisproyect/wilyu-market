# Wilyu Market V8 Operativa

Migrado a Supabase:
- Categorías
- Productos
- Fotos / Storage
- Proveedores
- Métodos de pago
- Tasas
- Pedidos
- Seguimiento de pedidos
- Registro/login de clientes
- Perfil del cliente
- Login de administrador

Todavía el carrito vive localmente en el navegador, lo cual es normal para un ecommerce.

## Prueba rápida
1. npm.cmd install
2. npm.cmd run dev
3. Administrar → entra con la cuenta admin de Supabase.
4. Crea proveedor.
5. Crea método de pago.
6. Ajusta tasa VES.
7. Crea producto con foto.
8. Haz un pedido como cliente.
9. Copia el código WY-... y úsalo en “Ve tu pedido”.
10. En Administración cambia el pedido a “En camino” y vuelve a consultarlo.
